# OpenQC Roadmap

## v0.x Stabilization

- Align Gaussian, ORCA, GAMESS, QE, and CP2K behavior with the standalone newtontech LSP repositories.
- Add fixture-based smoke tests for each supported input family.
- Document extension-host development and packaging commands.
- Refresh screenshots for the Marketplace listing.

## v1.0 Public Release

- Publish a stable VS Code Marketplace build.
- Provide sample files for every advertised format.
- Add a compatibility table for VS Code versions and optional Python/LSP dependencies.
- Define a contribution path for adding or updating standalone LSP backends.

## Later

- Add conversion between common input formats.
- Add batch structure preview and image export.
- Add calculation monitoring integrations for local or cluster workflows.
